# TarefasCodificaMaisPraTi

Repositório criado para armazenar todas as atividades, exercícios e práticas desenvolvidas durante o curso realizado no programa MaisPraTi em parceria com a Codifica, no período de maio a agosto de 2023.

## 📚 Objetivo

Registrar a evolução prática no aprendizado de desenvolvimento web e lógica de programação através das atividades realizadas em aula.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## 💻 Conteúdo do Repositório

O repositório contém:

- Exercícios práticos
- Atividades avaliativas
- Desafios de lógica
- Manipulação do DOM
- Estruturação de páginas web
- Práticas de estilização com CSS
- Exercícios de JavaScript

## 📖 Aprendizados

Durante o curso foram desenvolvidas habilidades em:

- Lógica de programação
- Estruturação HTML
- Estilização responsiva
- Programação com JavaScript
- Organização de código
- Versionamento de projetos
- Resolução de problemas

## 🎓 Contexto do Projeto

As atividades deste repositório foram realizadas durante o programa MaisPraTi em parceria com a Codifica, acompanhando aulas práticas, exercícios e avaliações propostas ao longo da formação.
